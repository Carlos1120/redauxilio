# RedAuxilio

PWA colaborativa para consultar y reportar información de emergencias en un mapa. Proyecto académico del equipo 4.

## Equipo

- Carlos Mario Peña
- Santiago Ortiz Ochoa

Interlocutor académico: Javier Charry. Contacto, aceptación de participación y aprobación del proyecto pendientes.

## Alcance previsto

- Puntos de asistencia, refugios, centros de acopio y vías afectadas.
- Desaparecidos, avistamientos y solicitudes de ayuda.
- Consulta pública, filtros, registro y publicaciones georreferenciadas con fotografías.
- Confirmación comunitaria, verificación oficial, vigencia y estados.
- Moderación, permisos y auditoría.
- Instalación PWA, consulta previa sin red y borradores locales. Una publicación solo se confirma después de recibir respuesta del servidor.

## Tecnología prevista

Monolito modular con Java/Spring Boot, Thymeleaf, Bootstrap, JavaScript, PostgreSQL, Spring Data JPA, Spring Security y Leaflet. Manifiesto, service worker e IndexedDB para la PWA. Versiones, proveedor cartográfico y entorno de despliegue pendientes de definir.
